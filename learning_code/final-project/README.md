# Final Project - Product Manager

## Mục tiêu

Xây một ứng dụng quản lý sản phẩm bằng JavaScript thuần, tổng hợp kiến thức trước khi học React.

## Yêu cầu chức năng

- [ ] Hiển thị danh sách sản phẩm từ dữ liệu hoặc API.
- [ ] Thêm, sửa và xóa sản phẩm.
- [ ] Tìm kiếm, lọc và sắp xếp.
- [ ] Validate form và hiển thị lỗi rõ ràng.
- [ ] Có loading, empty và error state.
- [ ] Lưu dữ liệu phù hợp vào localStorage.
- [ ] Giao diện dùng được trên điện thoại.

## Yêu cầu code

- [ ] Không viết toàn bộ logic trong một function.
- [ ] Không mutate array/object khi cập nhật state.
- [ ] Tách code thành module khi cần.
- [ ] Tên biến và function mô tả đúng nhiệm vụ.
- [ ] Xử lý trường hợp dữ liệu rỗng và request lỗi.

## Hoàn thành

Project hoàn thành khi một người khác có thể mở ứng dụng, sử dụng toàn bộ chức năng và đọc được cấu trúc code của bạn.
