# Exercises - Destructuring

> Hãy làm bài trong các file `exercise-*.js` trước khi mở `SOLUTIONS.md`.

## Bài 01 - Củng cố cú pháp

### Bài này để làm gì?

Giúp bạn nhớ cú pháp cốt lõi của Destructuring và tự theo dõi được input, xử lý, output.

### Yêu cầu

1. Không nhìn lại code ví dụ, hãy tự viết một ví dụ ngắn để lấy dữ liệu từ array hoặc object vào các biến riêng.
2. Dùng dữ liệu khác với README bài học.
3. In hoặc hiển thị kết quả để kiểm tra.
4. Thử thêm một trường hợp dữ liệu khác và dự đoán kết quả trước khi chạy.

Làm bài tại: `exercise-01.js`.

## Bài 02 - Áp dụng thực tế

### Bài này để làm gì?

Giúp bạn biết khi nào nên dùng Destructuring trong một chương trình thực tế và luyện cách chia bài toán thành bước nhỏ.

### Yêu cầu

Viết lại một đoạn code JavaScript theo cú pháp ES6+, ưu tiên code dễ đọc và không sửa dữ liệu gốc.

1. Ghi chú input mà chương trình nhận vào.
2. Dùng Destructuring để lấy dữ liệu từ array hoặc object vào các biến riêng.
3. Kiểm tra happy path và ít nhất một trường hợp đặc biệt.
4. Viết một câu giải thích output nhận được.

Làm bài tại: `exercise-02.js`.
