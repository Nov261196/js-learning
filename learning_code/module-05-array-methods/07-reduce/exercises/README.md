# Exercises - reduce

> Hãy làm bài trong các file `exercise-*.js` trước khi mở `SOLUTIONS.md`.

## Bài 01 - Củng cố cú pháp

### Bài này để làm gì?

Giúp bạn nhớ cú pháp cốt lõi của reduce và tự theo dõi được input, xử lý, output.

### Yêu cầu

1. Không nhìn lại code ví dụ, hãy tự viết một ví dụ ngắn để gộp một array thành một kết quả duy nhất.
2. Dùng dữ liệu khác với README bài học.
3. In hoặc hiển thị kết quả để kiểm tra.
4. Thử thêm một trường hợp dữ liệu khác và dự đoán kết quả trước khi chạy.

Làm bài tại: `exercise-01.js`.

## Bài 02 - Áp dụng thực tế

### Bài này để làm gì?

Giúp bạn biết khi nào nên dùng reduce trong một chương trình thực tế và luyện cách chia bài toán thành bước nhỏ.

### Yêu cầu

Xử lý một danh sách sản phẩm hoặc người dùng bằng đúng array method của bài và lưu kết quả vào biến mới.

1. Ghi chú input mà chương trình nhận vào.
2. Dùng reduce để gộp một array thành một kết quả duy nhất.
3. Kiểm tra happy path và ít nhất một trường hợp đặc biệt.
4. Viết một câu giải thích output nhận được.

Làm bài tại: `exercise-02.js`.
