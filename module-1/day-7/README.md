# Day 7

## Học gì

- Object
- Key và value
- Truy cập dữ liệu trong object
- Thêm dữ liệu vào object
- Sửa dữ liệu trong object
- Dùng for...in với object

## Khó chỗ nào

- Dễ nhầm giữa object và array
- Khó hiểu key/value
- Dễ truy cập sai dữ liệu
- Chưa quen dùng for...in

## Cách giải

- Dùng object để gom dữ liệu liên quan
- Dùng dấu chấm để truy cập dữ liệu
- Dùng [] để truy cập theo key
- Dùng for...in để loop object

Ví dụ:

- user.name
  - lấy name

- user["age"]
  - lấy age

- user.city = "HCM"
  - thêm dữ liệu

- user.age = 20
  - sửa dữ liệu

## Ghi chú

- Object lưu dữ liệu dạng key/value
- Dấu chấm là cách truy cập phổ biến nhất
- for...in dùng để duyệt key trong object
- Nên đặt tên key rõ nghĩa
