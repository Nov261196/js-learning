# Day 6

## Học gì

- Function với array
- Tính tổng array
- Tìm max và min trong array
- Tính trung bình cộng
- Đếm số lẻ trong array
- return trong function

## Khó chỗ nào

- Chưa quen truyền array vào function
- Dễ quên return
- Dễ loop sai điều kiện
- Khó hiểu cách cập nhật max và min

## Cách giải

- Dùng function để xử lý array
- Dùng for để duyệt từng phần tử
- Dùng biến sum để cộng dồn
- Dùng count để đếm số lượng

Ví dụ:

- nếu numbers[i] > max
  - cập nhật max

- nếu numbers[i] % 2 !== 0
  - tăng count

- average:
  - tổng / số phần tử

## Ghi chú

- numbers là tham số nhận array
- return dùng để trả kết quả ra ngoài
- Không nên hardcode length
- Nên format code rõ ràng
