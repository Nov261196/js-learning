# Day 5

## Học gì

- String
- length
- index trong string
- toUpperCase()
- toLowerCase()
- trim()
- includes()
- Duyệt string bằng for

## Khó chỗ nào

- Chưa quen duyệt từng ký tự
- Dễ nhầm giữa string và array
- Khó hiểu cách đếm ký tự trong chuỗi
- Dễ loop sai điều kiện

## Cách giải

- Dùng text.length để lấy độ dài chuỗi
- Dùng text[i] để lấy ký tự hiện tại
- Dùng for để duyệt từng ký tự
- Dùng biến count để đếm số lần xuất hiện

Ví dụ:

- nếu text[i] === "a"
  - tăng count

- toUpperCase():
  - chuyển thành chữ hoa

- trim():
  - xóa khoảng trắng dư

- includes():
  - kiểm tra chuỗi có chứa ký tự hoặc từ không

## Ghi chú

- String cũng có thể duyệt bằng for
- Index bắt đầu từ 0
- count++ dùng để tăng biến đếm
- Không nên hardcode độ dài chuỗi
