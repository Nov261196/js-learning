# Day 2

## Học gì

- Vòng lặp for
- Câu điều kiện if
- Toán tử % (chia dư)
- Cộng dồn bằng biến (sum)
- Giai thừa (factorial)
- Số nguyên tố (prime number)

## Khó chỗ nào

- Chưa quen vòng lặp for
- Hay sai điều kiện trong if
- Khó hiểu logic số nguyên tố
- Dễ đặt sai giá trị ban đầu (result = 0 sẽ sai)

## Cách giải

- Dùng for để lặp từ 1 đến n
- Dùng biến sum để cộng dồn
- Dùng % để kiểm tra chia hết

Giai thừa:

- Tạo biến result = 1
- Lặp từ 1 đến n
- Mỗi lần nhân vào result

Số nguyên tố:

- Nếu n < 2 thì không phải
- Lặp từ 2 đến sqrt(n)
- Nếu chia hết thì loại ngay

## Ghi chú

- % là phép chia dư
- break dùng để dừng loop sớm
- Math.sqrt(n) giúp tối ưu code
