# Day 3

## Học gì
- Function
- Tham số
- Return
- Cách gọi function
- Tái sử dụng logic bằng function

## Khó chỗ nào
- Chưa hiểu rõ return
- Dễ nhầm giữa return và console.log
- Khó tư duy chuyển logic cũ thành function
- Hay quên gọi function

## Cách giải
- Viết logic bình thường trước
- Sau đó bọc lại thành function
- Dùng return để trả kết quả
- Dùng console.log khi gọi function để kiểm tra kết quả

Ví dụ:
- sum(a, b): trả về tổng
- isEven(n): kiểm tra số chẵn
- factorial(n): tính giai thừa
- isPrime(n): kiểm tra số nguyên tố

## Ghi chú
- Function giúp tái sử dụng code
- return dùng để trả dữ liệu ra ngoài
- console.log chỉ dùng để in kết quả
- Nên chia mỗi bài thành một function riêng
