# Frontend MVC

Ứng dụng browser JavaScript thuần, không cần bước build.

```text
frontend/
├── assets/
├── pages/
├── public/favicon/
├── scripts/
│   ├── controllers/  # Nhận sự kiện và điều phối model/view
│   ├── models/       # State và nghiệp vụ khóa học
│   ├── views/        # Render giao diện HTML
│   ├── services/     # HTTP và Markdown
│   ├── data/         # Nội dung 16 module và bài luyện tập
│   ├── workers/      # Chạy code trong sandbox trình duyệt
│   └── main.js
├── styles/
└── index.html
```
