# Exercises - DOM Practice

> Hãy làm bài trong các file `exercise-*.js` trước khi mở `SOLUTIONS.md`.

## Bài 01 - Củng cố cú pháp

### Bài này để làm gì?

Giúp bạn nhớ cú pháp cốt lõi của DOM Practice và tự theo dõi được input, xử lý, output.

### Yêu cầu

1. Không nhìn lại code ví dụ, hãy tự viết một ví dụ ngắn để render dữ liệu và cập nhật giao diện từ state.
2. Dùng dữ liệu khác với README bài học.
3. In hoặc hiển thị kết quả để kiểm tra.
4. Thử thêm một trường hợp dữ liệu khác và dự đoán kết quả trước khi chạy.

Làm bài tại: `exercise-01.js`.

## Bài 02 - Áp dụng thực tế

### Bài này để làm gì?

Giúp bạn biết khi nào nên dùng DOM Practice trong một chương trình thực tế và luyện cách chia bài toán thành bước nhỏ.

### Yêu cầu

Kết hợp nhiều kiến thức đã học thành một luồng: chuẩn bị dữ liệu, xử lý và hiển thị kết quả.

1. Ghi chú input mà chương trình nhận vào.
2. Dùng DOM Practice để render dữ liệu và cập nhật giao diện từ state.
3. Kiểm tra happy path và ít nhất một trường hợp đặc biệt.
4. Viết một câu giải thích output nhận được.

Làm bài tại: `exercise-02.js`.
